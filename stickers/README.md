# 表情包目录说明

本目录用于存放客户端「表情包（贴纸）」功能所使用的素材，**无需修改任何代码**，按下面的约定放置文件即可自动生效。

## 目录结构约定

```
stickers/
├── 表情包组A/            ← 一个子文件夹 = 一个表情包组
│   ├── logo.png          ← 该组封面（展示在"表情包组选择区"）
│   ├── 开心.png           ← 组内表情包，文件名即表情包名
│   ├── 无语.jpg
│   └── 加油.png
├── 表情包组B/
│   ├── logo.jpg
│   └── 跳舞.gif
└── 表情包组C/            ← 允许没有 logo（选择区显示占位图标）
    └── 单图.png
```

规则要点：

1. **一个子文件夹 = 一个表情包组**，文件夹名即组名（会显示在表情包区域上方）。
2. **封面文件必须命名为 `logo`**（`logo.png` / `logo.jpg` / `logo.webp` / `logo.gif` / `logo.bmp` 均可），
   它会显示在"表情包组选择区"中；若没有 logo，选择区显示一个占位图标（不影响使用）。
3. **组内其余图片都是表情包**，**文件名（去掉扩展名）就是该表情包的名字**，会作为鼠标悬停提示与图片替代文本。
4. 支持的格式：`png` / `jpg` / `jpeg` / `webp` / `gif` / `bmp`。
5. 表情包服务端会自动压缩到**最长边 256 像素**后下发（透明 PNG 保留透明通道，GIF 动图保留动画不重编码），
   压缩结果缓存在 `data/_sticker_cache/`，无需手动清理。

## 随机表情（如骰子）

如果一组文件采用 **`名字_1.png`、`名字_2.png` …** 的「同前缀 + 连续序号」命名，
它们会被自动识别为一个**随机表情系列**：

- 面板里**只显示一个格子**（角标标注 `🎲N`，N 为可选张数）；
- 每次点击**随机抽一张**发送出去，对标 QQ 的骰子。

内置的默认组就是这样做的：

```
stickers/默认表情包/
├── logo.png
├── 骰子_1.png     ← 六面骰子
├── 骰子_2.png
├── ...
└── 骰子_6.png
```

该组在客户端**首次打开表情包面板时会自动缓存到本地**，用户无需手动点「下载」即可直接使用。
发送后消息名会显示为「骰子 5点」这类直观文案。

> 注意：至少要 2 个序号文件才会组成系列；只有一个（如 `a_1.png`）会按普通表情处理。

## 排列顺序

包选择区里 **`默认表情包` 固定排在最前（最左）**，其余表情包组按目录名排序。
若把默认组改名，排序会自动回落到纯目录名顺序（前端不再自动下载，手动点一次「下载」即可）。


## 客户端使用方式

1. 在**好友私聊**或**群聊**中，点击工具栏的 🧩 按钮打开表情包面板。
2. 首次选择某个表情包组时，面板会提示是否下载；点击「下载该表情包」后，
   该组会被缓存到浏览器本地（IndexedDB），之后可离线秒开。
3. 点击任意表情即可发送，气泡内以较小尺寸展示，点击图片可放大查看。

> 注意：**与辉夜（AI）的对话不支持表情包**，该入口会自动隐藏，只能使用 emoji 表情。

## 安全说明

- 表情包图片仅通过 `/stickers/<组名>/<文件名>` 站内路径分发，服务端对组名与文件名做了白名单与目录穿越校验。
- 消息中只保存相对路径，且发送接口会校验地址必须位于 `/chat_images/` 或 `/stickers/` 之下，
  外部 URL 与 `data:` 等写法一律拒绝，避免注入与外部资源跟踪。
